# TestDriver Setup for Square Open Source Portal

## Prerequisites
1. Install TestDriver: `npm install -g testdriverai`
2. Set up your TestDriver API key: `npx testdriverai config` or set `TESTDRIVER_API_KEY` environment variable

## Local Development Setup
1. Install Jekyll dependencies:
   ```bash
   gem install bundler
   bundle install
   ```

2. Start the Jekyll server:
   ```bash
   bundle exec jekyll serve
   ```
   The site will be available at http://localhost:4000

## TestDriver Configuration

1. Create the lifecycle directory structure:
   ```bash
   mkdir -p testdriver/lifecycle
   ```

2. Create `testdriver/lifecycle/provision.yaml` (see provisionYaml below)

3. Create `testdriver/lifecycle/prerun.yaml` (see prerunYaml below)

## Generate Exploratory Tests

Generate 5 exploratory tests to discover issues:
```bash
cd testdriver
npx testdriverai generate web 5
```

This will create exploratory tests in `testdriver/tests/` that will test various aspects of the portal.

## Review and Convert to Regression Tests

1. Review the generated exploratory tests in `testdriver/tests/`
2. Run them to see what TestDriver discovers:
   ```bash
   npx testdriverai run tests/
   ```
3. Convert successful exploratory tests to regression tests:
   ```bash
   npx testdriverai generate web 5 --write
   ```

## Running Tests

```bash
# Run all tests
npx testdriverai run tests/

# Run specific test
npx testdriverai run tests/test-name.yml
```

## CI/CD Integration

Add to your `.travis.yml` or GitHub Actions workflow:
```yaml
- name: Run TestDriver tests
  run: |
    npm install -g testdriverai
    cd testdriver
    npx testdriverai run tests/
  env:
    TESTDRIVER_API_KEY: ${{ secrets.TESTDRIVER_API_KEY }}
```

## Rationale

This setup is recommended for the Square Open Source Portal because:

1. **Jekyll Static Site**: The project uses Jekyll, which requires Ruby and bundler. The provision file handles this dependency installation.

2. **Local Development Server**: The prerun file starts the Jekyll server and waits for it to be ready, ensuring tests run against a live instance at localhost:4000.

3. **Exploratory Testing First**: Using `npx testdriverai generate web 5` creates exploratory tests that will intelligently discover the portal's features including:
   - Repository card listings and navigation
   - Category filtering functionality
   - External links to GitHub repositories
   - Image loading and display
   - Responsive design across viewports
   - Search and filter capabilities

4. **CI/CD Ready**: The setup integrates with existing Travis CI configuration, allowing automated testing on pull requests.

5. **Static Content Testing**: Perfect for testing static sites where content is generated from repos.json and rendered via Mustache templates.

6. **Cross-Platform**: PowerShell commands work on Windows, macOS, and Linux, ensuring consistency across development environments.

The exploratory tests will help discover edge cases and issues with the repository listings, while regression tests can be created from successful explorations to prevent future breakage.
