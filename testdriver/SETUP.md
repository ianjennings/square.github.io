## 🚀 Setup Instructions

1. **Production URL Found**: The production URL is https://square.github.io - this is a GitHub Pages site hosted by Square's organization. This is confirmed by the repository name 'square.github.io' which follows GitHub Pages convention for organization sites.

2. **How TestDriver Accesses It**: TestDriver will launch Chrome directly to https://square.github.io using the provision.yaml lifecycle file. The provision script starts Chrome with the hardcoded production URL and waits for the page to load by checking for 'Square' text.

3. **Running Test Generation**: 
   - First, set up your TD_API_KEY as a GitHub secret
   - Generate initial tests: `npx testdriverai@latest generate --app-type web --count 5`
   - Tests will be created in testdriver/generate/ directory
   - The generate workflow will automatically create tests when pushing to mechanic/setup-testdriver* branches
   - Run tests manually: `npx testdriverai@latest run testdriver/generate/*.yaml`
   - Tests will automatically run on pull requests and pushes to main/master branches

## Rationale

This approach is ideal for testing Square's open source portal because:

1. **Production URL Identified**: The repository name 'square.github.io' is the standard GitHub Pages convention for organization sites. This means the site is hosted at https://square.github.io - no building required.

2. **Static Site Testing**: This is a Jekyll-based static website that showcases Square's open source projects. The site is already built and deployed via GitHub Pages, so TestDriver can directly access and test the live production version.

3. **No Build Process Needed**: Since this is a static site hosted on GitHub Pages, we don't need to build it ourselves. The site is continuously deployed and accessible at the production URL.

4. **Simple Workflow Structure**: The workflows are straightforward - generate tests when setting up TestDriver, and run tests on PRs/pushes to ensure the site continues to function correctly.

5. **Comprehensive Testing Opportunities**: The site has rich functionality to test including repository listings, category filtering, navigation, image loading, and links to individual projects - all perfect for exploratory TestDriver tests.

6. **Direct Access**: The provision.yaml hardcodes the production URL directly in the Chrome launch command, making the setup simple and reliable.
